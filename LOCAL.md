# Local development

## On this machine (Linux)

```bash
cd portsmouthbadmintonhub   # or /workspace/portsmouthbadmintonhub
npm install
npm run dev
```

Open: http://localhost:5173/portsmouthbadmintonhub/

Production build test:

```bash
npm run build
npm run preview
```

Open: http://localhost:4173/portsmouthbadmintonhub/

## On your PC (Windows)

Same commands in **PowerShell** from `C:\Side\portsmouthbadmintonhub`:

```powershell
npm install
npm run dev
```

See **SETUP-WINDOWS.md** for copying files from GitHub.
